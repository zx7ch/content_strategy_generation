# 故障排查

---

## 启动问题

### ❌ 双击 start.command 没有反应

**原因**：macOS 首次运行未认证程序会被拦截。

**解决**：
1. 右键点击 `start.command` → **打开**（不是双击）
2. 弹窗点击 **打开**
3. 之后双击即可正常启动

> 💡 **找不到终端？** 终端即 macOS 自带的 **Terminal 应用**，在 Launchpad → 其他 里可以找到。双击 `start.command` 会自动打开它，不需要手动去找。

---

### ❌ 终端窗口一闪而过，或显示"找不到 xhs-runtime"

**原因**：`start.command` 和 `xhs-runtime` 不在同一个文件夹里。

**解决**：确保以下文件都在同一个目录：
```
xhs-runtime        ← 必须在同级
start.command
```
`config.env` 模板通常也会在同级目录，但真实配置文件会在首次启动后生成到：
`~/Library/Application Support/xhs-growth-agent/config.env`

---

### ❌ 浏览器显示"请启动本地 Agent Runtime"

**原因**：Runtime 没有在运行，或者启动失败。

**解决**：
1. 检查终端窗口（Terminal）是否还开着，如果已关闭请重新双击 `start.command`
2. 如果终端里有报错文字，截图后参考下方对应场景处理

## 配置问题

### ❌ 任务执行失败，日志显示"API key 无效"或"authentication error"

**原因**：真实配置文件里的 `ANTHROPIC_API_KEY` 填错了。

**解决**：
1. 用文本编辑器打开 `~/Library/Application Support/xhs-growth-agent/config.env`
2. 确认 Key 以 `sk-ant-` 开头，中间没有多余空格
3. 保存后重启 Runtime（关闭终端窗口 → 重新双击 `start.command`）

---

### ❌ 任务一直卡在"采集数据"，或报"小红书爬虫失败"

**原因 1**：Cookie 已过期（有效期约 7 天）。

**解决**：
1. 重新登录 [小红书网页版](https://www.xiaohongshu.com)
2. 按 `F12` → Network → 刷新页面 → 点任意请求 → 复制 Cookie 字段
3. 粘贴到 `~/Library/Application Support/xhs-growth-agent/config.env` 的 `XHS_SPIDER_COOKIES=` 后，保存
4. 重启 Runtime

**原因 2**：Cookie 格式不完整。

**解决**：确保复制的是完整的 Cookie 字符串（通常很长，包含 `a1=`、`web_session=` 等多个字段）。

---

### ❌ 任务失败，日志显示"Last error: 'a1'"

**原因**：Cookie 里缺少关键的 `a1` 字段，说明复制的 Cookie 不完整，或者账号未登录。

**解决**：重新登录小红书网页版后再获取 Cookie。

## 使用问题

### ❌ 选题库是空的

**可能原因 1**：任务还没有点「已完成」。

**解决**：回到创作台，找到已完成的任务，点击 **已完成** 按钮，系统才会将内容写入选题库。

**可能原因 2**：刚刚重启了 Runtime，选题库数据还在加载。

**解决**：刷新浏览器页面，等待几秒后数据应该出现。

**可能原因 3**：切换了品牌，当前品牌下没有历史数据。

**解决**：检查左上角选中的品牌是否正确。

---

### ❌ 生成的笔记内容质量不佳，或与需求不符

**解决**：
- 在创作台对话框里追加要求，例如："请重新生成，更偏向种草风格，少用数据"
- 或者新建一次任务，在初始需求里描述得更具体（目标人群、内容风格、差异化方向）

---

### ❌ 任务执行中途失败，进度卡住不动

**解决**：
1. 刷新页面，确认任务状态
2. 如果任务显示失败，可以在对话框中发送"重新执行"或新建一次任务
3. 如果终端里出现报错文字，截图后反馈给我们

---

## 性能问题

### ⚠️ 第一次运行很慢（卡在"正在初始化"）

**原因**：首次运行需要下载 AI 向量模型（约 400MB），视网络情况需要 5-15 分钟。

**解决**：耐心等待，进度条结束后后续运行会正常。如果长时间没有进展，检查网络连接。

---

### ⚠️ 运行过程中 Mac 风扇转速很高

**原因**：向量计算和 AI 调用会短暂占用 CPU，属于正常现象。

**说明**：任务完成后 CPU 占用会恢复正常。

## 数据与隐私

### 我的数据存在哪里？

所有数据（生成的笔记、选题、历史记录）存储在本地 `~/Library/Application Support/xhs-growth-agent/` 目录下，不会上传到任何服务器。

### 升级 Runtime 后数据还在吗？

在。数据和真实配置都存储在 `~/Library/Application Support/xhs-growth-agent/`，与 exe 安装目录完全独立，重新打包不会影响数据，也不需要重新填写已有 API Key 或 Cookie。

如果新版 Runtime 的配置模板增加了字段，启动时会自动把缺失字段追加到真实 `config.env`，并生成一个 `config.env.bak-*` 备份文件。终端会提示新增了哪些配置项，请按提示检查。
