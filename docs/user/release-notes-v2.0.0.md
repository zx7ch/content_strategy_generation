## 本次更新

### 可追溯的内容调研

Creator 现在提供完整的内容调研流程：

1. 输入要研究的品类、品牌或产品，例如“夏季凉感T恤”。
2. 确认系统对调研主体的理解。
3. 选择“产品营销”等调研方向。
4. 检查并按需修改最终搜索词。
5. 确认后由系统采集公开内容、整理证据并生成调研报告。

搜索词只有在用户确认后才会冻结并交给采集流程。输入框保持焦点时也可以直接点击确认，不再需要先点击输入框外部。

### 基于证据的营销结论

报告会尝试从三个角度分析公开样本：

- **场景与需求**：用户在什么场景下产生需求，以及真实体验中存在的问题。
- **可被相信的产品卖点**：哪些产品价值获得了样本支持，哪些仍存在反向证据。
- **内容表达**：样本中出现了哪些值得参考的表达方式。

三个角度是分析计划，不要求每次都产出三条结论。只要至少一个角度形成可发布结论，报告就可以生成；证据不足的角度会明确保留为空缺，不会为了凑数而生成结论。

每条结论均展示样本数量和独立作者数量。点击“证据详情”可在当前卡片内展开原文引用，同一时间只展开一条引用。

### 更清楚的调研进度

调研期间可以随时点击右侧的“查看 Trace”，查看：

- 需求确认和搜索范围是否已经冻结；
- Spider 当前处于检索、详情采集还是数据整理阶段；
- 证据筛选和三条分析轨道的状态；
- 报告是否正在组装、等待恢复或已经完成；
- 哪些成功结果会在重试时直接复用。

“证据不足”和“技术故障”现在是两种不同状态。证据不足允许报告按已有结论稀疏发布；模型返回异常、持久化失败等技术故障会进入恢复状态，避免把系统错误包装成研究结论。

### 安全恢复，不重复浪费

- 某条分析轨道发生技术故障时，已经成功的轨道结果会被持久化保留。
- 恢复时只重试失败部分，不会重新执行已经完成的分析。
- 如果分析成功但报告组装失败，可以只继续生成报告，不会重新调用 Spider 搜索。
- 应用重启后可以继续读取同一 Run 的 Trace、分析结果和历史报告。

### LLM 与小红书登录配置

- LLM 改为用户自行配置的 OpenAI-compatible 服务，可填写 Base URL、模型和 API Key，并在保存前测试连接。
- 小红书采集推荐使用 Cookie 登录。Cookie 失效后，可在 Creator 右侧重新粘贴并保存，无需重新创建调研任务。
- API Key 和 Cookie 不会出现在 Trace、报告或前端状态响应中。

## 开始使用

1. 解压 `xhs-runtime.zip`。
2. 打开 `xhs-runtime/start.command`，等待 Runtime 启动。
3. 在 Creator 右侧展开“模型服务”，填写并测试 LLM 配置。
4. 在“小红书登录”中粘贴有效 Cookie 并保存，确认状态为“已登录”。
5. 点击输入区的“内容调研”，输入研究主题并发送。
6. 依次确认调研主体、调研方向和搜索词。
7. 调研进行时可随时打开 Trace；报告完成后可展开证据详情。

发布前已用“夏季凉感T恤”完成真实操作录屏验收。录屏使用真实 LLM、Cookie 和 Spider，没有演示字幕或模拟成功结果；视频只保存在验收机器，不上传代码仓库或发布压缩包。

## 如何理解报告状态

| 状态 | 含义 |
|---|---|
| 已选定 | 当前证据达到该角度的发布门槛，可以作为报告结论使用。 |
| 方向性结论 | 有真实证据支持，但样本量或独立作者数仍不足，必须结合限制阅读。 |
| 证据不足 | 系统完成了分析，但当前样本不能支持可靠结论。 |
| 分析不可用 | 发生模型响应、数据处理或持久化等技术故障，需要恢复后再发布。 |
| 审计撤回 | 原始分析结果被保留，但可信度审计认为它不应出现在本次最终报告中。 |

报告反映的是本次搜索词和公开样本，不代表完整市场事实。方向性结论尤其适合用于提出下一步验证问题，不适合直接当作确定结论对外宣传。

## 数据与隐私

- Run、Trace、冻结搜索词、证据索引、分析结果和报告保存在本机 Runtime 数据目录中，应用升级或重启不会主动清除。
- 调研会访问小红书公开内容，并把完成分析所需的提示和证据发送给用户配置的 LLM 服务。
- API Key 和 Cookie 会保存在本机配置中；请只在可信电脑上使用，不要分享 Runtime 数据目录或配置文件。
- 发布压缩包不包含开发环境的 `.env`、数据库、Cookie、API Key 或本地采集数据。

## 已知限制

| 限制 | 说明 |
|---|---|
| 小红书 Cookie 会过期 | 页面显示 `auth_required` 或“登录状态已失效”时，需要粘贴新 Cookie 后继续。 |
| 扫码登录可能受环境影响 | 当前推荐 Cookie 登录；二维码不可用时不会影响 Cookie 采集路径。 |
| 小红书风控和页面变化 | 可能导致样本较少或采集失败。请先检查登录状态，再根据 Trace 决定是否重试。 |
| 不保证三轨都有结论 | 系统会尝试分析三轨，但只发布获得证据支持的结果。 |
| 不直接发布到小红书 | 报告需要由用户审核和使用，应用不会自动发布内容。 |
| 不生成配图 | 当前版本专注于调研证据和营销结论。 |
| macOS 桌面版 | 当前候选包为 Apple Silicon（ARM64）；Intel 包由正式 Release 流程单独构建。 |
| 尚未 Apple 公证 | 当前内部候选包使用 ad-hoc 签名，首次打开可能出现 Gatekeeper 提示。 |

首次执行研究 embedding 时可能需要下载模型，耗时取决于网络环境。LLM 费用取决于用户选择的服务商、模型、样本量和重试次数，本版本不提供固定费用估算。
