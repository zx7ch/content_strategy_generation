# 版本说明 v0.1.0

**发布日期**：2026-05-31
**版本类型**：内部种子版本（仅限受邀用户）


---

## 这个版本能做什么

### 🎯 内容策略生成

通过一次对话，自动完成从市场调研到笔记草稿的完整流程：

1. **竞品内容采集** — 自动搜索小红书相关内容，按热度筛选高质量参考
2. **差异化策略分析** — 识别内容机会、受众痛点、选题方向
3. **笔记草稿生成** — 产出多篇可直接参考的笔记（含标题、正文、标签、封面方向建议）
4. **选题库沉淀** — 每次完成的内容自动进入选题库，跨次积累

### 📚 选题库

- 展示所有完成任务后产出的笔记选题
- 每条选题包含核心假设、预测潜力分、完整正文
- 数据本地持久化，重启后不丢失

### 🔒 本地优先

- 所有数据存储在你自己的电脑上，不经过第三方服务器
- AI 调用直连 Anthropic，内容不留存

## 这个版本不能做什么

| 功能 | 说明 |
|---|---|
| 直接发布到小红书 | 需手动复制内容到小红书 App 发布 |
| 生成配图 | 仅提供封面创意方向文字描述，不生成图片 |
| Windows 支持 | 当前仅支持 macOS |
| 多品牌并行工作流 | 每次只能运行一个任务 |
| 历史笔记效果追踪 | 无法关联已发布笔记的实际数据表现 |
| 移动端 | 仅支持桌面浏览器 |

## 已知问题

**小红书登录状态可能失效**
Cookie 有效期会受小红书网页端状态影响。失效后请在 Creator 的「内容调研」右侧栏重新扫码，或直接粘贴新的 Cookie；保存后即时生效，重启 Runtime 后仍会保留。

**选题库存在重复选题**
同一主题多次生成时，选题库可能出现标题相似的条目，暂无去重机制。

**首次启动需下载模型**
第一次运行需要下载约 400MB 的 AI 向量模型，视网络情况需等待 5-15 分钟。后续启动正常。

**爬虫受小红书反爬限制**
部分时段或搜索词可能触发小红书的风控，导致采集数据较少或失败，重试通常可恢复。

**每次任务有 API 费用**
每次完整流程约消耗 $0.5-2 的 Anthropic API 费用，请留意账户余额。
