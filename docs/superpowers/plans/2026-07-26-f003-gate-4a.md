# F003 Gate 4A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the preview-gated Lite contract the only Creator research contract.

**Architecture:** Freeze a three-direction catalog plus a user-selected, non-empty requested subset. Creator reads only `/lite-report`; that route also returns selected frozen citation detail. Delete old report and EvidenceBundle slices only after proving Gate 2 artifacts read from retained citation/checkpoint/source/trace data.

**Tech Stack:** Python/FastAPI/Pydantic/SQLite/pytest; Next.js/React/TypeScript/node:test/Playwright.

## Global Constraints

- Catalog is `product_marketing`, `competitor_discovery`, `content_performance`; Brief shows all, run freezes non-empty `requested_direction_ids`.
- `not_requested` is a shared read-model/audit state only; reports render requested directions only.
- Requested direction failures remain `insufficient_evidence` or `unavailable`; no silent omission.
- Retain only `/lite-report`; no `/report`, `/results`, `/evidence-bundles`, fallback, or EvidenceBundle model/table.
- Preserve Gate 2 run/checkpoint/source/citation/trace/acceptance evidence.
- `F003_LITE_PREVIEW_ENABLED` defaults off: no Creator entry and create/confirm returns `F003_LITE_PREVIEW_DISABLED`; it never gates one direction.
- Browser tests call real Lite APIs; controlled durable backend data, not frontend mocks, creates deterministic UI states.
